# 폴더 그룹 한국어 문구 교정 내역

`agent-workspace/task/folder-shortcuts-data/copy-ko-groups.md` 초안을 공식 문체 가이드(`official.md`)와 기존 폴더 화면 문구(`ko.js`) 기준에 맞춰 교정한 내역이다.

## 1. 교정 내역

| 키 / 작업 | 변경 전 | 변경 후 | 사유 |
|:---|:---|:---|:---|
| `groupEmpty` | 폴더를 이곳으로 드래그하면 이 그룹에 넣을 수 있습니다. | 폴더를 이곳으로 드래그하여 이 그룹에 추가하십시오. | 화면 안내 지시문 종결 규칙(-하십시오)을 적용하고, 구어적 가능형 표현(-하면 넣을 수 있습니다)을 화면 안내에 맞게 명확하고 격식 있는 공식 문체로 교정함. |
| `ungroupedDrop` | 폴더를 이곳으로 드래그하면 그룹에서 뺄 수 있습니다. | 폴더를 이곳으로 드래그하여 그룹에서 제외하십시오. | 화면 안내 지시문 종결 규칙(-하십시오)을 적용하고, 구어 표현('뺄 수 있습니다')을 격식 있는 공식 문체('제외하십시오')로 교정함. |
| `folders.reorder` (whenToUse) | 메뉴 막대와 앱 창에서 폴더가 표시되는 위치를 바꿀 때 사용합니다. 위치는 폴더가 속한 구역 안에서 세며 1이 맨 위입니다. 구역의 항목 수보다 큰 수를 지정하면 맨 아래로 이동합니다. 그룹을 지정하면 그 그룹으로 옮기고 ungrouped를 지정하면 그룹에서 뺍니다. | 메뉴 막대와 앱 창에서 폴더가 표시되는 위치를 바꿀 때 사용합니다. 위치는 폴더가 속한 구역 안에서 세며 1이 맨 위입니다. 구역의 항목 수보다 큰 수를 지정하면 맨 아래로 이동합니다. 그룹을 지정하면 해당 그룹으로 이동하고 ungrouped를 지정하면 그룹에서 제외합니다. | 구어적 표현('옮기고', '그룹에서 뺍니다')을 공식 문체이자 기존 용어('이동하고', '그룹에서 제외합니다')로 교정하고 지칭 대상을 명확히 함('그 그룹' → '해당 그룹'). |
| `folders.reorder` (input.group) | 그룹 / 폴더를 옮길 그룹입니다. 이미 있는 그룹이어야 합니다. | 그룹 / 폴더를 이동할 그룹입니다. 이미 있는 그룹이어야 합니다. | 명령어 요약(summary: 다른 위치나 그룹으로 이동) 및 설명문과 어휘를 '이동'으로 통일함. |
| `folders.reorder` (input.ungrouped) | 그룹에서 빼기 / 폴더를 그룹에서 뺍니다. | 그룹 제외 / 폴더를 그룹에서 제외합니다. | 구어 표현('빼기', '뺍니다')을 공식 문체로 교정하고, 라벨을 간결한 명사구('그룹 제외')로 정돈함. |
| `folders.add-group` (whenToUse) | 한 프로젝트의 폴더처럼 관련된 폴더를 메뉴 막대와 앱 창에서 하나의 제목 아래 묶을 때 사용합니다. 그룹은 필요할 때만 쓰며 그룹이 없는 폴더는 맨 위에 표시됩니다. 대소문자를 구분하지 않고 기존 그룹과 다른 이름이어야 합니다. | 한 프로젝트의 폴더처럼 관련된 폴더를 메뉴 막대와 앱 창에서 하나의 제목 아래 묶을 때 사용합니다. 그룹은 선택 사항이며 그룹이 없는 폴더는 맨 위에 표시됩니다. 대소문자를 구분하지 않고 기존 그룹과 다른 이름이어야 합니다. | 원문 'Groups are optional'의 구어적 의역('필요할 때만 쓰며')을 소프트웨어 공식 표준 역어인 '선택 사항이며'로 교정함. |
| `folders.add-group` (input.position) | 위치 / 그룹 사이에서 놓을 위치입니다. 1부터 세며 지정하지 않으면 맨 뒤에 추가됩니다. | 위치 / 그룹 목록에서 놓을 위치입니다. 1부터 세며 지정하지 않으면 맨 뒤에 추가됩니다. | 원문 'among the groups'의 어색한 직역투('그룹 사이에서')를 자연스러운 한국어 표현인 '그룹 목록에서'로 교정함. |
| `folders.rename-group` (whenToUse) | 저장한 폴더 그룹의 이름을 바꿀 때 사용합니다. 그룹 안의 폴더는 그대로 남습니다. | 저장한 폴더 그룹의 이름을 바꿀 때 사용합니다. 그룹 안의 폴더는 그대로 유지됩니다. | 기존 `folders.rename`('그대로 유지됩니다') 및 요약(summary: '폴더는 유지')과 어조·용어를 맞추기 위해 '남습니다'를 '유지됩니다'로 교정함. |
| `folders.rename-group` (input.name) | 새 이름 / 그룹에 붙일 이름입니다. | 새 이름 / 그룹에 지정할 이름입니다. | 일상적인 구어 표현인 '붙일 이름입니다'를 공식 문체에 부합하는 '지정할 이름입니다'로 정돈함. |
| `folders.remove-group` (whenToUse) | 그룹 제목을 없앨 때 사용합니다. 그룹 안의 폴더는 삭제되지 않고 그룹이 없는 구역의 끝으로 옮겨지며 디스크의 내용은 변경되지 않습니다. | 그룹 제목을 삭제할 때 사용합니다. 그룹 안의 폴더는 삭제되지 않고 그룹이 없는 구역의 끝으로 이동하며 디스크의 내용은 변경되지 않습니다. | 구어적 표현인 '없앨 때'를 기능 명칭(삭제)과 맞춰 '삭제할 때'로 교정하고, 수동태 표현('옮겨지며')을 능동형인 '이동하며'로 정돈함. |
| `folders.reorder-group` (input.position) | 위치 / 놓을 위치입니다. 1부터 셉니다. | 위치 / 이동할 위치입니다. 맨 위 위치 번호는 1입니다. | 기존 `folders.reorder.input.position`('이동할 위치입니다. 맨 위 위치 번호는 1입니다.')과 설명을 통일하고 단절된 구어체 표현('1부터 셉니다')을 격식 있게 교정함. |

## 2. 질문

뜻이 불분명하여 해석이 유보된 항목은 없으며, 모든 초안 항목의 영어 원문과 화면 맥락이 명확하여 계획대로 교정을 완료했습니다.
