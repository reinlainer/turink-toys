# 0.2.0 릴리즈

착수일: 2026-10-08
완료일: 2026-10-08
상태: 완료

## 범위

0.1.0 이후의 변경을 0.2.0 으로 릴리즈한다. 앱 삭제 기능, 앱 창 화면 통폐합, 휴지통 이름 기록, Finder 빠른 동작 이름 정리가 담긴다.

## 수행

- 버전을 0.2.0 으로 올렸다. 루트와 세 패키지의 `version` 외에 `@turink/core` 를 가리키는 앱·CLI 의 의존 버전(`"0.1.0"` 고정)과 `package-lock.json` 의 같은 값도 함께 올렸다. 의존 버전을 두면 `npm ci` 가 레지스트리에서 `@turink/core@0.1.0` 을 찾다가 실패한다
- 커밋 `bfeeaa8`, 태그 `v0.2.0` 을 push 했다
- 릴리즈 워크플로(`Release v0.2.0`)가 시험, 번들, 압축, 게시, 캐스크 갱신을 마치고 성공했다

## 검증

- 단위 시험 39건 통과, `npm ci --dry-run` 통과, `turink-toys --version` 이 0.2.0
- 게시된 `turink-toys-0.2.0.zip`(128,305,586 바이트)의 sha256 이 탭 저장소의 캐스크 값과 같다 (`db03b01…1dc5`)

## 확인하지 못한 것

- `brew install` / `brew upgrade` 로 0.2.0 을 실제로 설치해 보지 않았다
- 덮개 설정(관리자 암호 창 경로)은 0.2.0 에도 실행 검증 전이다(`status.md` 현안)
