## 목표

앱 전원 화면의 두 설정 카드(디스플레이를 연 상태에서 잠자기 방지, 디스플레이를 닫은 상태에서 잠자기 방지)의 설명과 경고를 꼭 필요한 내용만 남겨 간결하게 고친다. 긴 문단 대신 한 줄 요약과 불릿 목록으로 표시한다.

## 표시 구조 변경

| 구분 | 변경 전 | 변경 후 |
|:---|:---|:---|
| 설명 | 한 문단(`keepAwakeBody`, `lidBody`) | 한 줄 요약(같은 키) |
| 세부 사항 | 문단 안에 포함 | 불릿 목록(`keepAwakePoints`, `lidPoints`. 줄바꿈으로 항목 구분) |
| 경고 | 세 문장 | 핵심 한두 문장(`lidWarning`) |

번역 조회가 문자열 값만 다루므로 목록은 배열이 아닌 줄바꿈 구분 문자열로 둔다. 언어마다 항목 수가 달라도 된다.

## 내용 판단

- 남길 내용: 기능이 하는 일, 디스플레이 꺼짐과 덮개 닫힘 시 동작, 적용 전원, 관리자 암호, 자동 복원, 과열 경고, 배터리 소모
- 뺀 내용: 「전원 어댑터 사용 시 [배터리] 설정이 이미 켜져 있으면 동작이 달라지지 않음」. 예외 상황의 부연이며 화면 상단 타일이 현재 전원의 자동 잠자기 설정을 이미 표시함
