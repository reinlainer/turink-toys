# 추가 한국어 문구 교정본 (2회차)

2회차 추가 한국어 문구 6건의 공식 문체 교정본이다. 각 항목은 키, 초안 문구, 교정 문구로 구성한다.

| 키 | 초안 문구 | 교정 문구 |
|:---|:---|:---|
| result.keepAwakeNote | 디스플레이를 닫으면 잠자기 상태로 전환됩니다. 디스플레이를 닫은 상태에서도 잠자기 상태로 전환되지 않게 하려면 power.lid(디스플레이를 닫은 상태에서 잠자기 방지)를 사용하십시오. | 디스플레이를 닫으면 잠자기 상태로 전환됩니다. 디스플레이를 닫은 상태에서도 잠자기 상태로 전환되지 않게 하려면 power.lid(디스플레이를 닫은 상태에서 잠자기 방지)를 사용하십시오. |
| result.lidWarning | 이제 디스플레이를 닫아도 잠자기 상태로 전환되지 않습니다. 자동 복원되기 전에는 Mac을 가방 등 통풍이 되지 않는 곳에 넣지 마십시오. | 디스플레이를 닫아도 잠자기 상태로 전환되지 않습니다. 자동 복원되기 전에는 Mac을 가방 등 통풍이 되지 않는 곳에 넣지 마십시오. |
| menu.openAtLogin | 로그인 시 열기 | 로그인 시 열기 |
| ui.loginItem.label | 로그인 시 열기 | 로그인 시 열기 |
| ui.loginItem.failed | 로그인 항목 설정을 변경하지 못했습니다. | 로그인 항목 설정을 변경하지 못했습니다. |
| ui.loginItem.needsApproval | 시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램에서 Turink Toys를 허용하십시오. | 시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램에서 Turink Toys를 허용하십시오. |

## 확인한 macOS 표기 출처

- **설정 화면 경로(시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램) 및 기능 명칭(로그인 시 열기)**:
  - Apple 대한민국 공식 지원 문서: [Mac에서 로그인 항목 및 확장 프로그램 설정 변경하기](https://support.apple.com/ko-kr/guide/mac-help/mtusr003/mac)
  - 경로 확인: Apple 메뉴() > 시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램 (영어판 System Settings > General > Login Items & Extensions에 정확히 대응)
