# 추가 한국어 문구 초안 (2회차)

1회차 이후 새로 생긴 한국어 문구다. 각 항목은 키, 표시 위치, 초안 문구로 구성한다. `power.lid` 같은 기능 식별자는 명령어 이름이므로 그대로 둔다.

## 사실 근거 (교정 시 바꾸지 않을 내용)

- 「잠자기 방지」를 켠 뒤에도 디스플레이를 닫으면 잠자기 상태로 전환된다. 디스플레이를 닫은 상태에서도 깨어 있게 하려면 별도 기능 「디스플레이를 닫은 상태에서 잠자기 방지」(명령어 `power.lid`)를 쓴다.
- 「디스플레이를 닫은 상태에서 잠자기 방지」를 켜면 지정한 시간에 자동 복원될 때까지 디스플레이를 닫아도 잠자기 상태로 전환되지 않는다.
- 「로그인 시 열기」는 macOS 로그인 시 앱을 자동으로 여는 설정이다. macOS의 Dock 메뉴에 있는 같은 이름의 항목(옵션 > 로그인 시 열기)과 같은 기능이다.
- macOS가 등록을 보류하면 사용자가 시스템 설정의 로그인 항목 화면에서 앱을 허용해야 한다. 최신 macOS 영어판 경로는 System Settings > General > Login Items & Extensions다. 한국어판 화면 이름은 웹 검색으로 확인해 원문대로 쓴다.

## 문구

| 키 | 표시 위치 | 초안 문구 |
|:---|:---|:---|
| result.keepAwakeNote | 잠자기 방지 실행 결과의 안내 | 디스플레이를 닫으면 잠자기 상태로 전환됩니다. 디스플레이를 닫은 상태에서도 잠자기 상태로 전환되지 않게 하려면 power.lid(디스플레이를 닫은 상태에서 잠자기 방지)를 사용하십시오. |
| result.lidWarning | 디스플레이를 닫은 상태의 잠자기 방지 실행 결과의 경고 | 이제 디스플레이를 닫아도 잠자기 상태로 전환되지 않습니다. 자동 복원되기 전에는 Mac을 가방 등 통풍이 되지 않는 곳에 넣지 마십시오. |
| menu.openAtLogin | 메뉴 막대 메뉴의 체크 항목 | 로그인 시 열기 |
| ui.loginItem.label | 앱 창 사이드바 하단의 체크박스 | 로그인 시 열기 |
| ui.loginItem.failed | 설정 변경 실패 알림 | 로그인 항목 설정을 변경하지 못했습니다. |
| ui.loginItem.needsApproval | macOS 허용이 필요할 때의 알림 | 시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램에서 Turink Toys를 허용하십시오. |
