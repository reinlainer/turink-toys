# power-copy 에이전트 팀 진행표

## 1. 작업 명세

### 1.1 목표
전원 기능의 한국어 문구를 전원 연결 여부(전원 어댑터, 배터리)에 따라 구분해 설명하도록 고치고, 정확하고 자연스러운 공식 문체로 교정한다.

### 1.2 완료 기준
- 동작이 전원 연결 여부에 따라 달라지는 문구가 모두 그 차이를 구분해 설명
- 공식 문체 가이드 기준으로 모든 단어와 표현을 점검하고 고친 곳 전부를 변경 대조표로 보고
- 관리자가 교정본을 코드(`packages/core/src/i18n/ko.js`)에 반영하고 기존 테스트와 CLI 출력 확인 통과

### 1.3 주요 지침
- 공식 문체 가이드: `agent-workspace/guides/writing-style/official.md` (특히 9절 교정)
- 프로젝트 문체: 서술 「-합니다/-됩니다」, 지시 「-하십시오」, 항목 이름과 상태 값은 명사구 (`packages/core/src/i18n/ko.js` 상단 주석)
- 사실은 바꾸지 않고 표현만 교정. 사실 근거는 초안 파일의 「사실 근거」 절

### 1.4 대상 리소스
- 대상 파일: `agent-workspace/task/power-copy-data/draft-ko.md`(초안, 읽기 전용), `agent-workspace/task/power-copy-data/draft-ko-reviewed.md`(교정본, antigravity-문서 작성)
- 참고 문서: `agent-workspace/task/power-copy.md`, `packages/core/src/i18n/ko.js`(다른 기능의 기존 문구 표기 확인용)
- 고치지 않을 파일: 소스 코드 전체(`packages/`), 초안 파일

### 1.5 참여 에이전트
| 식별자 | 제품과 모델 | 역할 | 실행 방식 | 실행 명령 |
