# 폴더 기능 한국어 문구 교정 변경 내역

`agent-workspace/task/folder-shortcuts-data/copy-ko.md` 초안을 공식 문체 가이드(`official.md`) 및 `packages/core/src/i18n/ko.js` 표기 규칙에 맞춰 교정한 내역입니다.

## 변경 내역

| 키 / 작업 항목 | 변경 전 | 변경 후 | 사유 |
|:---|:---|:---|:---|
| `ui.folders.subtitle` | 자주 여는 폴더를 메뉴 막대 아이콘에서 바로 엽니다. 줄을 드래그하면 순서가 바뀝니다. | 자주 여는 폴더를 메뉴 막대 아이콘에서 바로 엽니다. 항목을 드래그하여 순서를 변경할 수 있습니다. | 일상 구어 표현인 「줄」을 macOS UI 요소 표준 용어인 「항목」으로 바로잡고, 정중하고 격식 있는 서술문(-할 수 있습니다)으로 다듬었습니다. |
| `ui.folders.dropHint` | Finder에서 폴더를 이곳이나 메뉴 막대 아이콘으로 드래그하면 추가됩니다. | Finder에서 폴더를 이곳 또는 메뉴 막대 아이콘으로 드래그하여 추가하십시오. | 사용자 지시문 종결 규칙(-하십시오) 및 기존 `ko.js`의 `dropHint` 패턴을 준수하고, 구어적 연결 표현(「이곳이나」)을 공식적인 연결 표현(「이곳 또는」)으로 정돈했습니다. |
| `ui.folders.emptyDropBody` | Finder에서 폴더를 이 영역으로 드래그 | Finder에서 폴더를 이 영역으로 드래그합니다. | 서술어 어미가 생략된 불완전한 문장을 설명 문장 종결 규칙(-합니다)에 맞춰 완전한 서술문으로 교정했습니다. |
| `ui.folders.emptyMenuBody` | 이 창을 열지 않고 폴더 추가 | 이 창을 열지 않고 폴더를 추가합니다. | 불완전한 명사형 종결을 설명 문장 종결 규칙(-합니다)에 맞춰 완성된 서술문으로 교정했습니다. |
| `ui.folders.emptyButtonBody` | 폴더 선택 창에서 선택 | 폴더 선택 창에서 폴더를 선택합니다. | 목적어와 서술어가 생략된 표현을 설명 문장 종결 규칙(-합니다)에 맞춰 명확한 서술문으로 교정했습니다. |
| `task.folders.list` (title) | 저장한 폴더 | 저장한 폴더 목록 | 명령어 기능(저장된 폴더 목록 조회)을 명확히 하고, 기존 `apps.list` (「앱 목록」)와의 명명 일관성을 맞추었습니다. |
| `task.folders.list` (summary) | 바로 열기용으로 저장한 폴더 목록 | 바로 열기 위해 저장한 폴더 목록 | 구어적 표현(「~용으로」)을 공식 문체에 맞게 목적 표현(「~위해」)으로 정돈했습니다. |
| `task.folders.add` (summary) | 바로 열 폴더 저장 | 바로 열 수 있도록 폴더 저장 | 과도하게 압축되어 어색한 표현(「바로 열 폴더」)을 명확하고 자연스러운 수식 구조로 교정했습니다. |
| `task.folders.remove` (whenToUse) | 바로 열기 목록에서 폴더를 뺄 때 사용합니다. 폴더 자체와 그 안의 내용은 변경하지 않습니다. | 바로 열기 목록에서 폴더를 제거할 때 사용합니다. 폴더 자체와 그 안의 내용은 변경하지 않습니다. | 구어체 표현(「뺄 때」)을 공식 문서 표준 어휘이자 작업 제목과 일치하는 용어인 「제거할 때」로 교정했습니다. |
| `task.folders.reorder` (whenToUse) | 메뉴 막대와 앱 창에서 폴더가 표시되는 위치를 바꿀 때 사용합니다. 1이 맨 위이며 목록보다 큰 수를 지정하면 맨 아래로 이동합니다. | 메뉴 막대와 앱 창에서 폴더가 표시되는 위치를 바꿀 때 사용합니다. 1이 맨 위이며 목록의 항목 수보다 큰 수를 지정하면 맨 아래로 이동합니다. | 「목록보다 큰 수」라는 범주 오류(비문)를 원문 의미(「a number past the end」)에 맞게 「목록의 항목 수보다 큰 수」로 바로잡았습니다. |
| `task.folders.reorder` (input.position) | 위치 / 옮길 위치입니다. 맨 위를 1로 셉니다. | 위치 / 이동할 위치입니다. 맨 위 위치 번호는 1입니다. | summary의 「이동」과 용어를 통일하고, 구어적인 표현(「맨 위를 1로 셉니다」)을 명확하고 격식 있는 서술문으로 교정했습니다. |
| `task.folders.rename` (summary) | 저장한 폴더가 표시되는 이름 변경 | 저장한 폴더의 표시 이름 변경 | 어색하고 장황한 관형절(「폴더가 표시되는 이름」)을 간결하고 명확한 명사구(「폴더의 표시 이름」)로 정돈했습니다. |
| `task.folders.rename` (whenToUse) | 목록에서 폴더를 알아보기 쉬운 이름으로 표시할 때 사용합니다. 표시되는 이름만 바뀌며 실제 폴더 이름은 그대로입니다. 이름을 지정하지 않으면 원래 폴더 이름으로 돌아갑니다. | 목록에서 폴더를 알아보기 쉬운 이름으로 표시할 때 사용합니다. 표시되는 이름만 바뀌며 실제 폴더 이름은 그대로 유지됩니다. 이름을 지정하지 않으면 원래 폴더 이름으로 되돌아갑니다. | 공식 문서에 어울리도록 표현의 격조를 높이고(「그대로입니다」 → 「그대로 유지됩니다」), 복원 의미를 살려 「되돌아갑니다」로 정돈했습니다. |

## 질문

뜻이 불분명하여 교정을 진행하지 못한 항목은 없습니다. 모든 항목의 원문 의도와 화면 맥락이 명확합니다.

다만 다음 1건에 대해 사용자의 확인 및 선호를 여쭙고자 합니다.
- `task.folders.list`의 `title`: 영어 원문(`Saved folders`)을 직역하면 「저장한 폴더」이나, CLI/에이전트 도움말에서 목록 조회 작업임을 명확히 하고 다른 목록 작업(`apps.list`의 `앱 목록`)과 통일하기 위해 「저장한 폴더 목록」으로 교정했습니다. 원문 그대로 「저장한 폴더」를 선호하시는지, 교정본인 「저장한 폴더 목록」을 채택하실지 확인해 주십시오.
