## 목표

전원 기능의 한국어 문구가 전원 연결 여부(전원 어댑터, 배터리)에 따른 동작 차이를 구분해 설명하도록 고치고, 공식 문체 가이드에 맞춰 단어와 표현을 전수 점검한다. 상태 표시에는 값이 어느 전원 기준인지 함께 표시한다.

## 사실 근거

- 잠자기 방지(`caffeinate -i`)는 시스템의 자동 잠자기만 막으며 디스플레이 끄기에는 관여하지 않음. 전원 종류와 관계없이 같은 방식으로 동작
- macOS 노트북의 자동 잠자기는 전원별로 다름. 전원 어댑터 사용 시 [배터리] 설정의 「디스플레이가 꺼져 있을 때 전원 어댑터 사용 시 컴퓨터를 자동으로 잠자지 않게 하기」가 켜져 있으면 원래 잠자지 않음(이 Mac: 전원 어댑터 `sleep 0`, 배터리 `sleep 1`)
- 디스플레이 끄기 시간도 전원별 설정(「배터리 사용 시 비활성 상태인 경우 디스플레이 끄기」, 「전원 어댑터 사용 시 비활성 상태인 경우 디스플레이 끄기」). `pmset -g`는 현재 전원의 값만 보고함
- 디스플레이를 닫은 상태의 잠자기 방지(`pmset -a disablesleep`)는 전원 종류와 관계없이 적용
- 출처: Apple 「Mac의 잠자기 및 깨우기 설정 구성하기」(support.apple.com/ko-kr/guide/mac-help/mchle41a6ccd)
- 미확인: 닫은 디스플레이 모드(외장 디스플레이 사용 시)의 전원 어댑터 필요 조건은 Apple 공식 문서로 확인하지 못함. 문구에서 해당 내용을 제외
