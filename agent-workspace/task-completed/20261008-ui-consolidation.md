# 앱 창 화면 통폐합과 UI 개선

착수일: 2026-10-08
완료일: 2026-10-08
상태: 완료 (커밋 전)

## 요청

- 메뉴가 기능 단위로 너무 잘게 나뉘어 있다. 영역별 한 화면으로 통합
- 목업·테스트 앱 같은 인상을 없애고 보기 좋게 개선
- 라벨·설명 문구를 정확하고 자연스럽게 교정

## 결과

### 화면 구성 (메뉴 14 → 4)

| 화면 | 포함 기능 | 구성 |
|:---|:---|:---|
| 압축 | compress, extract, inspect, verify | 파일 놓기 영역 하나. 일반 파일이면 '압축하기', zip이면 '압축 풀기'·'검사' 전환. 검사는 내용 확인과 Windows 호환성 확인을 한 번에 하고 판정 카드로 표시. 인코딩 판별이 필요하면 예시 이름과 함께 후보를 고르게 함 |
| 디스크 정리 | targets, report, clean, restore | 확보 가능 공간 요약, 그룹별 대상 목록과 크기, 하단 실행 막대, 최근 정리에서 되돌리기. 이 Mac에 없는 위치는 접어 둠 |
| 앱 관리 | apps.list, uninstall, restore | 앱 아이콘·검색이 있는 목록, 하단 실행 막대, 앱별로 묶은 삭제 확인 창, 최근 삭제에서 되돌리기 |
| 전원 | status, keep-awake, lid | 상태 요약 3칸과 설정 카드 2개. 덮개 설정은 macOS 관리자 암호 창으로 실행 |

전용 화면이 없는 기능은 '기타' 화면에 자동 생성 양식으로 노출되도록 유지했다(현재 해당 없음).

### 설계 판단

- 코어 기능은 나누지 않았다. CLI·에이전트 계약이고, Finder 빠른 동작과 실행 기록이 기능 ID에 묶여 있다
- 개발자용 콘솔은 접을 수 있는 '활동 기록' 패널로 옮겼다(기본 닫힘, 새 기록이 오면 사이드바에 점 표시). 실행 중 진행은 하단 알림으로 보여 준다
- 명령줄 미리보기는 각 실행 영역의 '터미널 명령 복사' 아이콘 버튼으로 옮겼다
- 사실과 달랐던 '되돌릴 수 없음'과 의미 없던 '분량에 비례' 표시는 없앴다

### 함께 고친 결함

- **덮개 설정이 앱 창에서 항상 실패**: 관리자 권한 경로가 없었다. `power.lid` 만 macOS 관리자 암호 창(`do shell script … with administrator privileges`)으로 CLI를 실행하도록 추가. 입력은 매니페스트로 검증한 뒤 명령줄에 넣는다
- **파일 끌어다 놓기가 동작하지 않음**: Electron 32부터 `File.path` 가 없어졌다. `webUtils.getPathForFile` 로 교체
- **이미 되돌린 정리·삭제가 '최근' 목록에 계속 나옴**: 이후 복구 실행이 가리키는 원래 실행을 제외
- 화면을 열 때마다 하는 조회(앱 목록, 전원 상태, 용량)가 실행 기록에 쌓이지 않도록 기록 없는 조회 경로(`task:peek`) 추가

### 문구

- 앱 창 문구를 `packages/app/src/strings.js`(영어 원문)와 `i18n/ko.js` 의 `ui` 아래로 정리. 한국어·영어 모두 새로 씀
- 한국어 기능 이름 교정: 안전 압축→압축, 안전 해제→압축 풀기, 압축 파일 검사→압축 파일 내용 확인, 용량 리포트→용량 측정, 휴지통에서 복구→정리 되돌리기, 앱 복구→앱 되돌리기, 덮개 동작→덮개를 닫아도 깨어 있기, 유휴 절전 방지→잠자기 방지
- 말투를 '-세요/-니다'로 통일('하십시오' 제거), '절전'→'잠자기', '맥'→'Mac' 표기 통일, '되돌릴 수 없는 작업' 확인 메시지를 사실에 맞게 수정
- 영어 기능 이름은 Finder 빠른 동작 메뉴 이름이기도 해서 바꾸지 않음

## 검증

- 단위 시험 39건 통과
- Electron 창을 띄워 캡처하는 임시 스크립트로 네 화면과 주요 상태를 확인(라이트·다크, 한국어·영어)
  - 압축: 파일 2개 선택 상태, zip 선택 후 검사 결과, 실제 압축(`src.zip`)과 압축 풀기(`src-2`) 성공
  - 디스크 정리: 목록·크기·없는 위치 접기·최근 정리(이미 되돌린 기록 제외 확인)
  - 앱 관리: 실제 아이콘, Xcode 선택 후 삭제 확인 창 표시 → 취소(삭제 안 함)
  - 전원: 잠자기 방지 켜기 → 상태 반영 → 끄기
- 개발 빌드를 다시 만들어 `/Applications/Turink Toys-dev.app` 으로 교체, 실행 확인

## 확인하지 못한 것

- 덮개 설정(관리자 암호 창 경로): 암호 입력과 시스템 설정 변경이 필요해 실행하지 않음
- 실제 파일을 끌어다 놓는 동작: 캡처 스크립트로는 놓기를 재현할 수 없어, 같은 경로를 쓰는 미리 채우기로만 확인

## 참고

- 앱 아이콘: `app.getFileIcon` 은 모든 앱에 기본 아이콘을 돌려주고 `large` 크기는 Electron 44를 종료시킴. Quick Look 미리보기(`nativeImage.createThumbnailFromPath`)로 대체
- 최근 정리 목록의 `tt.probe` 1건은 `disk.clean` 이름 기록 작업의 충돌 시험에서 휴지통에 남긴 시험 폴더다

## 후속: 한국어 문구 공식 문체 교정 (2026-10-08)

사용자 요청으로 한국어 문구 전체를 공식적이고 정중한 문체로 다시 썼다. 기준은 Apple 한국어 macOS 사용 설명서에서 원문으로 확인한 표기다.

| 범주 | 기준 표기 | 확인 출처 |
|:---|:---|:---|
| 압축 | 압축 / 압축 해제 | Apple 'Mac에서 파일 및 폴더 압축 및 압축 해제하기'(mchlp2528) |
| 휴지통 | 휴지통으로 이동 / 되돌려 놓기 / 삭제 | Apple 'Mac에서 파일 및 폴더 삭제하기'(mchlp1093), '앱 삭제 또는 제거'(102610) |
| 잠자기 | 잠자기 상태 / 자동으로 잠자지 않게 하기 / 디스플레이 끄기 | Apple 'Mac의 잠자기 및 깨우기 설정 구성하기'(mchle41a6ccd) |
| 문체 | 설명 -합니다·-됩니다, 안내 -하십시오, 옵션 -하기 | 위 Apple 문서 전반 |

- 확인하지 못한 것: 노트북 덮개를 가리키는 Apple 공식 한국어 표기. Apple 커뮤니티 답변의 '디스플레이를 닫다'를 따랐다
- '다운로드'는 Apple 문서에서 직접 확인하지 못했고, macOS 폴더 이름과 Microsoft 한국어 문서의 일반 표기를 따랐다
- 목록에서만 빼는 동작은 '목록에서 제거'로 바꿔, 파일 삭제와 혼동되지 않게 했다
- 한국어가 단어 중간에서 줄바뀜되던 문제를 `word-break: keep-all` 로 수정
