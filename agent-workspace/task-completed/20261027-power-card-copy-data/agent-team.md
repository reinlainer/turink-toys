## 1. 작업 명세

### 1.1 목표
앱 전원 화면의 두 설정 카드 설명과 경고를 꼭 필요한 내용만 담은 한 줄 요약과 불릿 목록으로 간결하게 고친다.

### 1.2 완료 기준
- 초안의 모든 문구가 공식 문체 가이드와 `ko.js` 머리말의 표기 규칙에 맞음
- 사실 근거와 어긋난 내용이 없음
- 교정 문구를 `ko.js`에 반영하고 `npm test` 통과, 앱 화면에서 표시 확인

### 1.3 주요 지침
- 사용자 요구: 쓸데없는 말 없이 표현할 내용만 간단명료하게, 이해하기 쉽게, 공식적으로
- 공식 문체 가이드(`agent-workspace/guides/writing-style/official.md`). 불릿 항목은 명사형(간결한 명사구)으로 종결
- `packages/core/src/i18n/ko.js` 머리말의 규칙: 서술은 -합니다/-됩니다, 지시는 -하십시오, 고정 용어(잠자기 상태, 디스플레이를 닫은 상태 등)

### 1.4 대상 리소스
- 대상 파일: `agent-workspace/task/power-card-copy-data/draft-ko-reviewed.md`(교정본, 신규)
- 참고 문서: `draft-ko.md`, 공식 문체 가이드, `ko.js`의 `ui.power` 절
- 고치지 않을 파일: 소스 코드 전체, `draft-ko.md`
