# 전원 설정 카드 문구 초안

표시 구조: 카드 제목 아래에 한 줄 요약(`*Body`), 그 아래 불릿 목록(`*Points`, 한 줄이 항목 하나), 닫은 상태 카드에만 경고 문구(`lidWarning`, 주황색 작은 글씨).

## 1. 디스플레이를 연 상태에서 잠자기 방지

현재 문구(`keepAwakeBody`):

> 일정 시간 동안 사용하지 않아도 Mac이 자동으로 잠자기 상태로 전환되지 않도록 합니다. 디스플레이는 설정된 시간이 지나면 평소와 같이 꺼지며 디스플레이를 닫으면 잠자기 상태로 전환됩니다. 전원 어댑터를 사용할 때 [배터리] 설정의 「디스플레이가 꺼져 있을 때 전원 어댑터 사용 시 컴퓨터를 자동으로 잠자지 않게 하기」가 켜져 있으면 원래 잠자기 상태로 전환되지 않으므로 이 기능을 켜도 동작이 달라지지 않습니다.

| 키 | 담을 내용 | 초안 문구 |
|:---|:---|:---|
| `keepAwakeBody` | 사용하지 않아도 지정한 시간 동안 자동 잠자기가 일어나지 않음 | 지정한 시간 동안 Mac을 사용하지 않아도 잠자기 상태로 전환되지 않습니다. |
| `keepAwakePoints` 1 | 디스플레이는 설정대로 꺼짐 | 디스플레이는 설정된 시간이 지나면 꺼짐 |
| `keepAwakePoints` 2 | 디스플레이를 닫으면 잠자기 상태로 전환됨 | 디스플레이를 닫으면 잠자기 상태로 전환 |

## 2. 디스플레이를 닫은 상태에서 잠자기 방지

현재 문구(`lidBody`, `lidWarning`):

> 디스플레이를 닫은 상태에서 진행 중인 작업을 완료해야 할 때 사용합니다. 전원 어댑터와 배터리 중 어느 전원을 사용하든 디스플레이를 닫아도 잠자기 상태로 전환되지 않습니다. 관리자 암호가 필요하며 지정한 시간이 지나면 기존 설정으로 자동 복원됩니다.
>
> 이 기능을 사용하는 동안에는 Mac을 가방 등 통풍이 되지 않는 곳에 넣지 마십시오. 과열될 수 있습니다. 배터리를 사용할 때는 디스플레이를 닫은 상태에서도 배터리가 계속 소모됩니다.

| 키 | 담을 내용 | 초안 문구 |
|:---|:---|:---|
| `lidBody` | 디스플레이를 닫아도 지정한 시간 동안 잠자기 상태로 전환되지 않음 | 디스플레이를 닫아도 지정한 시간 동안 Mac이 잠자기 상태로 전환되지 않습니다. |
| `lidPoints` 1 | 전원 어댑터와 배터리 모두에 적용됨 | 전원 어댑터와 배터리 모두 적용 |
| `lidPoints` 2 | 켜고 끌 때 관리자 암호가 필요함 | 관리자 암호 필요 |
| `lidPoints` 3 | 지정한 시간이 지나면 기존 설정으로 자동 복원됨 | 지정한 시간이 지나면 기존 설정으로 자동 복원 |
| `lidWarning` | 과열 위험이 있어 가방 등에 넣지 말 것. 배터리 사용 시 계속 소모됨 | 과열될 수 있으므로 사용 중에는 Mac을 가방 등 통풍이 되지 않는 곳에 넣지 마십시오. 배터리를 사용하면 배터리가 계속 소모됩니다. |

## 사실 근거

- 잠자기 방지(`caffeinate -i`)는 자동 잠자기만 막으며 디스플레이 끄기와 덮개 닫힘 동작은 바꾸지 않음
- 닫은 상태 잠자기 방지(`pmset -a disablesleep 1`)는 전원 종류와 관계없이 적용. 켜기와 끄기 모두 관리자 권한으로 실행
- 지정 시간이 지나면 launchd 예약 작업이 기존 설정으로 복원
