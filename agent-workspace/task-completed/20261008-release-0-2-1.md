# 0.2.1 릴리즈

착수일: 2026-10-08
완료일: 2026-10-08
상태: 완료

## 범위

0.2.0 이후의 수정을 0.2.1 로 릴리즈한다.

- 메뉴 막대 아이콘이 2배 크기로 표시되던 문제(아이콘 생성 스크립트가 레티나 캡처 픽셀을 그대로 저장)
- 디스크 정리 화면에서 용량 계산 중 창이 멈추던 문제(기능 실행을 작업 스레드로 이동)
- 휴지통에 남은 항목이 최근 정리·삭제 내역에서 사라지던 문제
- 사이드바 로고를 실제 앱 아이콘으로 교체
- 한국어 '되돌려 놓기' → '되돌리기'

## 수행

- 0.2.0 과 같은 절차. 루트와 세 패키지의 `version`, 앱·CLI 의 `@turink/core` 의존 버전, `package-lock.json` 의 같은 값 13곳을 0.2.1 로 변경
- 커밋 `070495d`, 태그 `v0.2.1` push
- 릴리즈 워크플로 `Release 0.2.1`(run 37715523510): 시험, 아이콘 생성, 번들, 압축, 게시, 캐스크 갱신 전 단계 성공

## 검증

- 단위 시험 39건 통과, `npm ci --dry-run` 통과, `turink-toys --version` 이 0.2.1
- 게시된 `turink-toys-0.2.1.zip`(128,306,887 바이트)의 sha256 이 탭 저장소 캐스크 값과 같음 (`6a06e77…95f1`), 캐스크 version 0.2.1

## 확인하지 못한 것

- `brew upgrade` 로 0.2.1 을 실제로 설치해 보지 않았다. 이 Mac은 Homebrew 릴리스를 제거하고 개발 빌드를 쓰는 상태다
- 덮개 설정(관리자 암호 창 경로)은 여전히 실행 검증 전이다(`status.md` 현안)

## 참고
